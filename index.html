🛠️ 开发者 API 调用指南与快捷指令

本项目支持标准 HTTP GET 请求，可直接接入 iOS 快捷指令、Python 爬虫、Node.js 脚本或第三方聚合分发：

1. 聚合解析接口（推荐，自动识别平台）

GET /api/sv.php?url=你的分享文本或链接

2. 单平台独立接口（更低开销）

# 抖音（免 Cookie 原画直链/图集/实况）
GET /api/douyin/douyin.php?url=https://v.douyin.com/xxxx/

# 快手
GET /api/kuaishou/ksjx.php?url=https://v.kuaishou.com/xxxx/

# 小红书
GET /api/xiaohongshu/xhsjx.php?url=http://xhslink.com/xxxx/

# 哔哩哔哩
GET /api/bilibili/bilibili.php?url=https://b23.tv/xxxx/

3. 视频直链防盗链 403 代理

GET /api/svproxyurl.php?proxyurl=Base64编码后的视频直链&type=douyin

4. cURL 调用示例

curl -s "https://example.com/api/sv.php?url=https://v.douyin.com/xxxx/" | jq .
